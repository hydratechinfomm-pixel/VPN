## 💡 Pro Tips

1. **Print or Open in Split View:** Use V2RAY_QUICK_REFERENCE.md while executing commands

2. **Keep Terminal Open:** Have SSH connection to 114.29.236.236 open in separate terminal

3. **Save the API Token:** Generate with `openssl rand -hex 32` and save in password manager

4. **Test Before Proceeding:** Don't skip testing phases - they only take 5 minutes

5. **Bookmark Troubleshooting:** Both QUICK_REFERENCE.md and COMPLETE_SETUP.md have sections

6. **Monitor Logs:** During setup, keep `tail -f /var/log/xray/error.log` open in another terminal

7. **Back Up Config:** After setup, backup `/usr/local/etc/xray/config.json` regularly
